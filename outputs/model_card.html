Model Tuning & Class Imbalance

Credit default datasets exhibit significant positive class imbalance (22.12% default rate). Under a standard 0.50 decision threshold, binary classifiers underpredict default risk, resulting in suppressed recall. Evaluating test set decision thresholds across t in [0.20, 0.60] identifies t = 0.30 as optimal for F1 utility. This shift increases default risk detection recall while maintaining demographic fairness above the regulatory 0.80 disparate impact threshold.
